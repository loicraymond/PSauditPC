# PSauditPC
Script Powershell d'audit d'un ordinateur sous Windows.

Testés sous :
- Windows 10
- Windows 11


## Informations auditées
- Mises à jour via WSUS
- Windows Update Deployement Optmization
- Pare-feu Windows
- SMB (v1 et v2)
- RDP
- Antivirus Windows Defender
- Contrôle de Compte Utilisateur (UAC)
- Politique d'exécution Powershell
-
